# MOMO 默默 · 非遗漫游

一个严格保留参考图各自原始比例的四场景互动网页：

- 首页：无字原画作为独立背景，标题由 SVG 代码绘制，带金箔渐变、粗粝边缘、扫光、入场动画、水面波纹、金粉粒子和“灵珠照明”鼠标。
- 功能导航：以总览图作为第二部分，顶部和底部功能区域均可点击。
- 抽盲盒：九款非遗角色可选，也可随机抽取。
- 模型占位：抽取页中央提供可旋转、可随鼠标倾斜的 3D 盲盒，后续可替换为正式 GLB/GLTF 模型。
- 抽取结果：结缘签、收藏反馈和再次抽取。

直接用浏览器打开 `index.html` 即可体验。页面会在任何屏幕上按当前场景的原图比例等比缩放，四周不足区域自动留暗边。
